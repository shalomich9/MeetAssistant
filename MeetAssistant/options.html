1. Groq API Configuration

Free Tier Friendly

MeetAssistant queries the official Groq Chat Completions API. You need a free Groq API key to use this extension.

How to get your free key:
  1. Go to console.groq.com/keys and log in or create a free account.
  2. Click Create API Key and copy your key.
  3. Paste your key above and click Test Key.

🔒 Security notice: Your key is stored solely on your machine using Chrome's local storage API (chrome.storage.local). It is never sent to any third-party server, tracking service, or intermediary. Local browser storage is not an encrypted hardware enclave; do not install this extension on untrusted shared machines.

4. Storage & Privacy

MeetAssistant preserves zero server logs. Full meeting transcripts are never stored permanently; only a small rolling buffer is held in memory during the call.
